# Noon Academy Multan

Prototype website for Noon Academy Multan (Chemistry & Biology).

**Features:** student, teacher and admin login, class chat rooms, direct messages from teachers, attendance, editable timetable, homework, fees and receipts, admissions form, admin panel, Urdu/English switch.

**Demo logins** (password `1234`): student `ali`, teacher `numan`, admin `admin`.

**How it works:** the whole site is one file, `index.html`. Open it in any browser, or host it with GitHub Pages. Data is saved only in the visitor's own browser, so different phones do not share messages yet. A real shared version needs a back end (for example Firebase).
